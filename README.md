# Does Late Delivery Reduce Repeat Purchase? (Olist Marketplace Analysis)

A product analytics project using ~100K Brazilian e-commerce orders (2016–2018)
to test whether delivery delays hurt review scores and 90-day repeat purchase,
and to design an A/B test for a delivery-promise change.

**Tools:** PostgreSQL, Python (Pandas), Power BI
**Dataset:** [Olist on Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
**Problem statement:** see [docs/problem.md](docs/problem.md)
